# Robust-Image-Watermarking-IWT-SVD-Chaotic-SBox
I implemented a robust and secure digital image watermarking system using Chaotic S-Box encryption combined with IWT–SVD, and compares its performance with DWT–SVD and DCT–SVD techniques. The system is evaluated on multiple test images using PSNR, SSIM, and NCC metrics, including robustness analysis.
